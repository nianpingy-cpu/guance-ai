# v0.5 实施与验收计划

日期：2026-10-26。基线：桌面 `企业决策/观策AI-WebMVP-v0.4`，无 Git，已原样导入 4949090。v0.2 已定位并对照现有 AUDIT-v0.2.md。基线 20 测试、类型检查通过。

## 阶段与退出条件

1. 仓库基础：私有 GitHub 仓库、基线提交、Issue/分支/PR、CI 与贡献规则；原目录保留。
2. UI 减法：优先 Dashboard/Signals，再 Strategy/Review。四入口不变，Dashboard 单一指标带、一个趋势图、重点记录与下一步；Signals 列表优先，分布图按需展开；策略的证据分析与竞品详细信息按需展开，A/B 比较直接可见；复盘保留四项结果、输入和反馈任务，补充分析按需展开。
3. 功能回归：预算同步、证据修改复审、编辑与不可变快照、超预算阻止、缺失/零值重算、持久化、反馈任务去重与回流、导出/重置。新增缺陷须先有失败测试再修复。
4. 全页面 UI 监控与验收：启动本地站点，实际浏览四页，1440×1000、768×1024、390×844；检查横向溢出、图表标签、间距、抽屉/弹窗、筛选空状态；保存截图、问题及修复记录。此为本轮有限验收，不代表持续监控。
5. 交付：lint/typecheck/test/build、浏览器关键路径、独立审查和远端 CI；提交 PR；通过前不合并。输出启动步骤、截图、验证结果和未完成项。

## 视觉决策

- 四张原参考图已找回并逐张查看：采用浅色底、留白、直接可读的大数字、细线数据；不复制参考图中的荧光色和装饰。
- 色彩：冷白 #F5F7FA、纯白 #FFFFFF、海军蓝 #243E63、正文 #172033、次文 #526176、细线 #E2E7EE；状态色仅用于必要警示。
- 字体：统一本机现代无衬线字体，数字使用同字体等宽数字特性；不请求在线字体。
- 页面以“依据→决策→反馈”作为结构，记录 ID 与可操作证据链接为识别特征，减少独立卡片容器。
- 图表：保留已有独立 SVG 实现。工作台 Lupi 趋势，主题 Glance 排序，预算/计划实际 Basics；详细图按需展开，不引入 React 图表包。
