# 安装与手动操作

## 安装与数据

Windows使用GuanceAI-win-x64-0.6.0.exe，按向导选择目录。macOS使用对应CPU的DMG；各系统构建、签名、公证和安装状态先看RELEASE-v0.6.md。首次启动是模拟演示项目。

Windows数据：%APPDATA%/GuanceAI/data；macOS：~/Library/Application Support/GuanceAI/data。升级保留目录，卸载默认保留数据。删除目录前导出项目JSON并复制backups。

## 演示完整闭环

1. 左侧导出当前任务JSON备份；演示项目可恢复演示数据，业务项目拒绝重置。
2. 工作台→修改企业与预算→改6000元。策略页上限同步，原审批提示复审。
3. 市场情报→筛选小红书→打开S-01→重要性改低，填写备注并保存；刷新后保留。
4. 策略页展开消费者主题，点击证据回到原始情报。模拟来源始终保留模拟标记。
5. 比较A/B，编辑核心信息。A小红书填6000元会使合计超限；改回2000元，填写理由并确认审批快照。
6. 效果复盘按下表录入，核对合计和成本指标。将下一轮建议加入任务，再回情报页完成或重开。
7. 再改预算为5500元，原审批需复审，历史快照和复盘仍保留。

## 建业务项目与导入

设置→项目与备份→填写名称→选择真实业务→创建。新项目不带模拟情报、审批、成效；工作台填写产品、目标、预算和日期。切换项目互不影响，顶栏显示保存状态。

市场情报→导入情报→下载CSV模板→填写→选文件→预览成功/失败行→确认。真实项目的导入来源标为人工导入，请填写原文和链接。旧Web导出JSON在设置内预览、校验后导入为项目，重复备份不重复建项目。

## 公开采集与来源连接

情报页下方展开“采集与来源连接”→选RSS/Atom或网页→填完整公开链接→可选关联一项复盘建议→开始。每次最多100条订阅内容；完成后新情报入库、标为待核实，并完成关联反馈任务。

打开详情可查原始链接、发布时间；展开完整采集正文，可查采集时间、任务编号和内容摘要。原文没有发布时间时明确显示缺失。失败或中断显示原因，可手动重试；重复内容不再次入库。关闭应用后停止任务。

不执行网页脚本、不绕过登录、不自动跟随重定向；动态网页可改用最终公开链接或文件导入。设置→来源连接可保存应用凭据并查看官方能力；公众号、小红书、抖音本版仍待开通，保存凭据不会启用数据适配器。抖音官方关键词仅自身业务获批词、最近1天，不能竞品词。

## 接入模型

1. 设置→模型连接→DeepSeek预设或添加自定义服务商。
2. 填名称、基础地址、协议与密钥→保存。DeepSeek基础地址为https://api.deepseek.com；其他兼容服务按文档填写/v1等基础路径，不附加/chat/completions。
3. 获取模型列表，选ID后再次保存；不支持列表接口时手填准确ID。
4. 测试连接（可能计费）→设为默认。没有默认模型只阻止AI任务，本机编辑照常可用。
5. 策略页下方展开模型分析，按编号/标题搜索、选择1–100条情报→生成。企业资料和所选情报发给该服务商，调用可能计费。
6. 逐项核对主题引用、A/B预算，人工编辑并审批。引用不存在、超预算或生成期间依据变化会阻止覆盖/审批。原始生成版本、模型、提示词版本及引用进入项目备份。
7. 任务可取消；服务商仍可能计费。401、429、超时和格式错误均明确提示，不自动重复提交。

## WebDAV同步

设置→数据同步→填可读写目录、用户名、密码和至少12字符的独立同步口令→保存→测试并初始化目录（创建guance-v1子目录）→立即同步。

第二台设备填相同目录与口令后同步，在项目列表选择恢复的项目；各台分别配置模型/平台凭据。可启用运行期间每分钟同步，断网仍保存本机。任务进度和连接设置不跨设备同步，业务结果与反馈待办会同步。

冲突时核对项目名、预算和时间，先导出备份，再选本机或远端整个项目版本。未选版本另存“冲突保留”项目；再同步一次传递处理结果。远端不会自动覆盖未解决冲突。

口令丢失无法解密，首版不能在原目录轮换口令。换口令时先导出备份，使用新的空目录初始化，各台再连接新目录。停用同步删除本机同步凭据，业务数据和远端文件保留。

## 备份恢复

可迁移备份使用项目JSON：导出→在设置中预览、校验并导入→核对情报、审批、复盘和分析。先在测试项目验证。

本机数据库备份位于data/backups，包含系统加密设置；换机器后凭据可能不能解密。故障恢复时先退出程序，复制整个data目录留档，将故障前备份复制为data/guance.sqlite，原数据库及-wal/-shm文件一并移入另一备份目录，再启动。运行中不要替换数据库；较新版本数据库需要相应应用版本。

启动失败不会静默载入演示数据覆盖业务，请保留现场文件并使用最近有效备份。
