# 安装与手动操作

## 安装与数据

0.6.1已撤回真实业务试用推荐，请先导出项目备份。使用GuanceAI-win-x64-0.6.2.exe；macOS按CPU选择GuanceAI-mac-arm64-0.6.2.dmg或GuanceAI-mac-x64-0.6.2.dmg。首发构建/签名/公证和人工安装情况以对应发行记录为准，首次启动新数据目录时为模拟项目。

Windows数据：%APPDATA%/GuanceAI/data；macOS：~/Library/Application Support/GuanceAI/data。升级保留目录，卸载默认保留数据。删除目录前导出项目JSON并复制backups。

## 演示完整闭环

1. 左侧导出当前任务JSON备份；演示项目可恢复演示数据，业务项目拒绝重置。
2. 工作台→修改企业与预算→改6000元。策略页上限同步，原审批提示复审。
3. 市场情报→筛选小红书→打开S-01→重要性改低，填写备注并保存；刷新后保留。
4. 策略页展开消费者主题，点击证据回到原始情报。模拟来源始终保留模拟标记。
5. 比较A/B，编辑核心信息。A小红书填6000元会使合计超限；改回2000元，填写理由并确认审批快照。
6. 效果复盘按下表录入，核对合计和成本指标。将下一轮建议加入任务，再回情报页完成或重开。
7. 再改预算为5500元，原审批需复审，历史快照和复盘仍保留。

## 建业务项目与导入

设置→项目与备份→填写名称→选择真实业务→创建。新项目不带模拟情报、审批、成效；工作台填写产品、目标、预算和日期。切换项目互不影响，顶栏显示保存状态。

市场情报→导入情报→下载CSV模板→填写→选文件→预览成功/失败行→确认。真实项目的导入来源标为人工导入，请填写原文和链接。旧Web导出JSON在设置内预览、校验后导入为项目，重复备份不重复建项目。

## 添加情报：粘贴、采集与文件导入

### 粘贴模式：不需要登录或密钥

市场情报→“添加情报”，有两个入口：

1. **公众号文章链接**：在微信里打开文章→右上角“···”→“复制链接”→回到观策AI粘贴，一行一个，最多10篇；也可以上传包含公众号链接的 .txt/.csv 列表。应用只读取公开文章正文，不登录公众号后台、不使用 Cookie、不抓取账号历史。
2. **抖音 / 小红书文案**：在平台点“分享”→“复制链接/复制文案”→回到观策AI选择平台并保存。可同时填写一个清楚的标题；不填时自动取第一行。应用不会访问平台账号，也不会读取密码或 Cookie。

保存后进入市场情报，标记为待核实，并尽量保留原文链接、标题和正文。遇到微信“环境异常/需要验证”时，请打开文章复制全文，用“抖音/小红书文案”入口保存。

### 需要登录：登录窗口采集（实验）

市场情报→“添加情报”→“登录窗口采集（实验）”：

1. 选择抖音、小红书或公众号文章页，点“打开登录窗口”。
2. 在独立窗口中扫码/登录，并打开一篇视频、笔记或公众号文章；搜索页会保存当前可见链接。
3. 可选择只采集当前页，或在搜索结果页缓慢加载约20/50条；出现验证会停止。
4. 回到“添加情报”，点底部“采集当前页/搜索结果”；结果进入市场情报，标记为待核实。

登录状态保存在本机独立分区，应用不读取密码、不导出 Cookie。该模式只读取当前页面可见内容，不是官方 OAuth；平台页面改版或要求验证时可能失败。可在同一页点“清除登录状态”退出。

### 固定来源：RSS / 公开网页

情报页下方展开“高级采集 · RSS / 公开网页订阅”→选RSS/Atom或网页→填完整公开链接→可选关联一项复盘建议→开始。每次最多100条订阅内容；有新增有效结果后入库、标为待核实，并完成关联反馈任务；零新增或全部重复时保留待办。

打开详情可查原始链接、发布时间；展开完整采集正文，可查采集时间、任务编号和内容摘要。原文没有发布时间时明确显示缺失。失败或中断显示原因，可手动重试；重复内容不再次入库。关闭应用后停止任务。

公开网页/RSS 采集不执行页面脚本、不绕过登录、不自动跟随重定向；动态网页可改用最终公开链接或文件导入。需要登录的平台页面请使用上面的“登录窗口采集”，由你手动登录。

### 企业技术接入（开发人员/服务商）

设置→企业技术接入可保存公众号、小红书、抖音的 AppID/AppSecret，并查看官方登录/控制台入口。普通用户不需要填写，保存凭据也不会启用官方采集或登录；官方数据适配器仍待开通。

**应用ID/密钥不是账号密码。** 它们要在官方开放平台创建应用后获取；不要填公众号密码、抖音号密码、小红书密码或验证码。三个平台分别去哪里找、常见错误和“为什么没有一键登录”，见[设置填写说明](SETTINGS-GUIDE.md#一企业技术接入普通用户不用看)。抖音官方关键词仅自身业务获批词、最近1天，不能竞品词。

## 接入模型

1. 设置→模型连接→DeepSeek预设或添加自定义服务商。
2. 填名称、基础地址、协议与密钥→保存。DeepSeek基础地址为https://api.deepseek.com；其他兼容服务按文档填写/v1等基础路径，不附加/chat/completions。
3. 获取模型列表，选ID后再次保存；不支持列表接口时手填准确ID。编辑时留空密钥仅适用于同一站点，换站点须重新填密钥。
4. 测试连接（可能计费）→设为默认。没有默认模型只阻止AI任务，本机编辑照常可用。
5. 策略页下方展开模型分析，按编号/标题搜索、选择1–100条情报→生成。企业资料和所选情报发给该服务商，调用可能计费。
6. 逐项核对主题引用、A/B预算，人工编辑并审批。引用不存在、超预算或生成期间依据变化会阻止覆盖/审批。原始生成版本、模型、提示词版本及引用进入项目备份。
7. 任务可取消；服务商仍可能计费。401、429、超时和格式错误均明确提示，不自动重复提交。

## WebDAV同步

**WebDAV 不是必填项，不配置也能正常使用**，只是不能跨设备同步。可以把它理解成“属于你的网络文件夹”，应用把加密后的项目版本放进去。

### 最简流程（以坚果云为例）

1. 登录坚果云网页版→账户设置→安全选项→第三方应用管理→添加应用，生成**应用密码**。
2. 设置→跨设备同步（WebDAV）：地址填 `https://dav.jianguoyun.com/dav/`；用户名填坚果云登录邮箱；密码填刚生成的**应用密码**（不是网页登录密码）。
3. 点“生成”创建至少12位同步口令，保存到密码管理器；第二台设备要填同一段。
4. 点“保存并测试连接”，成功后点“立即同步”。应用会自动创建 `guance-v1` 子目录，**不用手动新建**。
5. 第二台填完全相同的地址、用户名、密码和口令，保存并测试后再同步；在项目列表选择恢复的项目。

其他网盘（Nextcloud、群晖等）的地址格式、两台电脑配置、常见错误和密码/口令区别，见[设置填写说明](SETTINGS-GUIDE.md#二webdav-跨设备同步)。

从0.6.1及更早版本升级时，先导出项目备份；所有设备升级后配置同一个**新的空WebDAV目录**，旧目录保留。新版不会自动修改旧同步目录，本机升级前自动备份。各端已有检查点无法确定先后时会保留冲突供核对。

变更站点/账号须重填密码，变更目录须明确填同步口令（迁移可填原口令）。可启用运行期间每分钟同步，断网仍保存本机。任务进度和连接设置不跨设备同步，业务结果与反馈待办会同步。

冲突时核对项目名、预算和时间，先导出备份，再选本机或远端整个项目版本。未选版本另存“冲突保留”项目；再同步一次传递处理结果。远端不会自动覆盖未解决冲突。

口令丢失无法解密，首版不能在原目录轮换口令。换口令时先导出备份，使用新的空目录初始化，各台再连接新目录。停用同步删除本机同步凭据，业务数据和远端文件保留。

## 备份恢复

可迁移备份使用项目JSON：导出→在设置中预览、校验并导入→核对情报、审批、复盘和分析。先在测试项目验证。

本机数据库备份位于data/backups，包含系统加密设置；换机器后凭据可能不能解密。手动恢复按以下顺序：

1. 退出全部观策AI窗口，确认程序已经退出。
2. 复制整个data目录到另一位置留档。
3. 将现用guance.sqlite及同目录存在的guance.sqlite-wal、guance.sqlite-shm移入另一备份文件夹。
4. 从backups复制一份已确认有效的.sqlite备份到data目录，重命名为guance.sqlite；保留原备份不动。
5. 启动并核对项目、预算、审批及复盘。较新数据库必须使用相应版本应用；schema3不能用0.6.1打开，回退时使用升级前备份。

启动失败不会静默载入演示数据覆盖业务，请保留现场文件并使用最近有效备份。
