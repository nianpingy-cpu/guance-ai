# 设置填写说明（0.6.2）

这份说明讲两件事：**普通用户怎样用最少的步骤添加情报**，以及少数企业技术人员才需要的 **AppID/密钥**、**WebDAV 跨设备同步**。

## 先看：普通用户不需要填任何密钥

请直接使用「市场情报 → 粘贴添加」，不需要登录平台账号，也不需要 AppID、AppSecret 或 Cookie：

1. **公众号文章**：在微信里打开文章 → 右上角“···”→“复制链接” → 回到观策AI粘贴 → “读取并添加文章”。一次最多10篇公开文章；也可以上传包含公众号链接的 .txt/.csv 列表。
2. **抖音 / 小红书**：在平台点“分享”→“复制链接/复制文案” → 回到观策AI选择平台并保存。
3. **批量或固定来源**：用 CSV/JSON 导入，或在高级采集里使用 RSS/Atom、公开网页。

保存后会进入“市场情报”，标记为待核实，并尽量保留原文链接、标题和正文。应用不登录平台账号、不读取密码或 Cookie、不绕过平台验证。

如果微信提示“环境异常/需要验证”，请打开文章复制全文，用“抖音 / 小红书文案”入口保存即可。

## 一、企业技术接入（普通用户不用看）

### 1. 先看对照表

| 平台 | 应用ID 在哪里找 | 密钥叫什么 | 本版现状 |
|---|---|---|---|
| 微信公众号 | 公众平台 → 设置与开发 → 基本配置 → 开发者ID(AppID) | 开发者密码(AppSecret) | 官方接口待开通；普通用户用文章链接粘贴 |
| 小红书 | 开放平台 → 应用管理 → 应用详情 → App ID | App Secret | 官方接口待开通；普通用户用分享文案粘贴 |
| 抖音 | 开放平台 → 控制台 → 应用管理 → 应用详情 → App ID | App Secret（也可能写 Client Secret） | 官方接口待开通；普通用户用分享文案粘贴 |

三者的前提都是：**先在官方平台注册开发者、创建应用，并拿到对应权限。** 个人账号不一定能申请，平台也可能要求企业资质、应用审核或能力单独申请。**普通用户不需要走这条路。**

### 2. 微信公众号怎么填

1. 用**公众号管理员微信**扫码登录 [微信公众平台](https://mp.weixin.qq.com/)。
2. 进入「设置与开发 → 基本配置」。
3. 复制「开发者ID(AppID)」。它通常以 `wx` 开头，不是公众号名称、微信号或原始ID。
4. 在同一页找到「开发者密码(AppSecret)」，生成或重置后立即复制。AppSecret 通常只完整显示一次。
5. 回到观策AI「设置 → 企业技术接入」：
   - 平台选“微信公众号”
   - 应用 ID 粘贴 AppID
   - 应用密钥粘贴 AppSecret
   - 点“保存到本机”

注意：需要已认证的公众号和对应接口权限。AppSecret 泄露后，请立刻到公众平台重置。它**不是**公众号登录密码。保存后仍不会启用官方采集；普通用户请用文章链接粘贴。

### 3. 小红书怎么填

1. 用已入驻的企业或商家账号登录 [小红书开放平台](https://open.xiaohongshu.com/)。
2. 完成开发者入驻，创建应用，并提交需要的数据能力审核。
3. 进入「应用管理 → 应用详情」，复制 App ID。
4. 在同一应用详情页复制 App Secret。
5. 回到观策AI「企业技术接入」保存。

注意：个人账号不一定能申请；能拿到哪些数据取决于平台实际批准的能力。App Secret **不是**小红书登录密码。不要购买或借用他人的应用密钥。

### 4. 抖音怎么填

1. 用抖音开放平台账号登录 [抖音开放平台](https://open.douyin.com/)。
2. 完成开发者资质认证，创建应用并通过审核。
3. 进入「控制台 → 应用管理 → 应用详情」，复制 App ID。
4. 在同一页复制 App Secret；有些页面写作 Client Secret。
5. 如果要做关键词搜索，还需要单独申请 `video.search` 能力。
6. 回到观策AI「企业技术接入」保存。

注意：`video.search` 仅限与自身业务相关的获批关键词、最近1天，不能查询竞品词或通用品类。没有获批时，保存凭据也不会启用采集。App Secret **不是**抖音登录密码。

### 5. 常见错误

- **填了账号密码**：错误。这里要的是开放平台应用的 AppID/AppSecret。
- **填了公众号名称、微信号、抖音号、小红书号**：错误。这些都不是应用 ID。
- **AppSecret 只复制了一半，或复制了空格**：保存前检查首尾。
- **用了别人的应用密钥**：不要这样做，也无法通过平台授权。
- **以为保存后就能采集**：本版不会。平台适配器和授权还没有验收。
- **找不到 AppSecret**：先确认应用已创建、资质和权限已通过；公众号后台可重置，开放平台按后台提示处理。

### 6. 为什么没有“直接登录”按钮

真正的官方登录至少需要：

1. 已经审核通过的应用；
2. 在平台登记过的回调地址；
3. 本应用实现好的 OAuth 授权流程；
4. 对应的数据接口和权限验收。

这四项目前都没有完成。现在放一个“登录”按钮，只会跳到平台后失败，或者让人误以为已经接通。等官方平台授权和适配器完成后，才会增加真正的授权登录入口。

**适用于普通用户的替代方式**：公众号公开文章链接粘贴、抖音/小红书分享文案粘贴、公开网页、RSS/Atom、CSV/JSON 文件导入。设置里的企业凭据只是给技术人员预留，不影响这些功能。

## 二、WebDAV 跨设备同步

### 1. WebDAV 是什么

可以把 WebDAV 理解成“属于你的网络文件夹”。观策AI 把项目版本加密后放进这个文件夹，另一台电脑再读出来，实现跨设备同步。

它不是必填项。**不配置也能正常使用**，只是不能在两台电脑之间自动同步业务数据。

### 2. 最简单的做法：用坚果云

1. 登录[坚果云网页版](https://www.jianguoyun.com/)。
2. 打开「账户设置 → 安全选项 → 第三方应用管理」。
3. 点「添加应用」，名称填 `GuanceAI`，生成一个**应用密码**并复制。
4. 回到观策AI「设置 → 跨设备同步（WebDAV）」，按下表填写：

| 字段 | 填什么 |
|---|---|
| WebDAV 目录地址 | `https://dav.jianguoyun.com/dav/` |
| WebDAV 用户名 | 你的坚果云登录邮箱 |
| WebDAV 密码 | 第 3 步生成的**应用密码**，不是网页登录密码 |
| 独立同步口令 | 点“生成”，至少12位；保存到密码管理器 |

5. 点“保存并测试连接”。成功后点“立即同步”。
6. 应用会自动在目录里创建 `guance-v1` 专用子文件夹，**不用手动新建**。

第二台电脑填**完全相同的地址、用户名、应用密码和同步口令**，保存并测试后再同步。

### 3. 其他网盘

| 网盘 | 地址示例 | 用户名 | 密码 |
|---|---|---|---|
| Nextcloud | `https://你的服务器/remote.php/dav/files/你的用户名/` | Nextcloud 用户名 | 登录密码，推荐使用应用密码 |
| 群晖 NAS | `https://你的NAS地址:5006/共享文件夹名/` | DSM 用户名 | DSM 登录密码 |
| 其他 WebDAV | 服务商提供的 HTTPS 目录地址 | 服务商账号 | 服务商密码或应用密码 |

要点：

- 地址必须是 **HTTPS 目录**，并且你的账号有**写入权限**。
- 不要填网盘网页首页、分享链接、带 `?` 或 `#` 的地址。
- 群晖不要只填 NAS 根地址，建议填到某个共享文件夹。
- 地址末尾有没有 `/` 都可以，应用会自己处理。

### 4. 两台电脑怎么配

1. **第一台**：填写并保存，点“保存并测试连接”，再点“立即同步”。
2. **第二台**：填同一个地址、用户名、密码和同步口令，保存并测试，再同步。
3. 同步完成后，在第二台的项目列表里选择恢复出来的项目。
4. 两台电脑各自配置模型和平台凭据；这些凭据不会跨设备同步。
5. 可勾选“运行期间每分钟自动同步”；关闭应用后停止自动同步。

### 5. 常见错误

- **401 / 403 或“凭据或权限无效”**：用户名、密码或应用密码不对，或者账号没有该目录的写权限。
- **连接失败 / 404**：地址不是 WebDAV 目录，或少了路径；检查是否把网页地址当成了 WebDAV 地址。
- **“同步口令错误或密文损坏”**：两台设备的同步口令不一致，或口令输错。同步口令不是 WebDAV 密码。
- **目录里已有旧版数据**：0.6.1 及更早版本升级时，所有设备先升级，然后配置**同一个新的空目录**，旧目录保留。
- **换了网盘/账号/目录**：换站点或账号要重新填 WebDAV 密码；换目录要明确填同步口令（迁移时可填原口令）。
- **忘记同步口令**：首版无法在原目录轮换或找回口令。先导出项目备份，再用新的空目录和新的口令重新初始化。

### 6. 密码和口令有什么区别

- **WebDAV 密码**：登录网盘用，交给网盘验证身份。
- **独立同步口令**：给观策AI 加密远端文件用，至少12位；它不会上传到远端，也不会进入项目导出。

两个都要保存好，但作用不同。建议 WebDAV 使用网盘的“应用密码”，同步口令用“生成”按钮生成并保存到密码管理器。
