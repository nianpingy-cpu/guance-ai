# 添加情报与公众号公开文章采集验收（0.6.2）

2026-10-30，根据企业高管/市场人员“不懂 AppID、密钥、Cookie，希望有更简单的登录/采集方式”的反馈，新增无需登录的“添加情报”流程，并复核抖音、小红书、微信公众号现状。

## 现状复核

### 抖音 / 小红书

- 当前应用没有官方数据适配器，`douyin`、`xiaohongshu` 任务会被拒绝，设置里保存的 AppID/AppSecret 也不会启用采集。
- 官方开放平台需要企业资质、创建应用、权限审核和 OAuth 回调；个人用户无法通过一个按钮直接完成。
- 直接抓取分享页或复用账号 Cookie 会受反爬、登录验证、频率限制和平台条款影响，不适合交给非技术用户，也不应作为稳定企业能力。

### 微信公众号

- 公众号历史文章接口依赖公众号后台 Cookie/token 或内部接口，需要抓包、填 Cookie、处理频率限制（如 200013）和封号风险，不适合市场人员。
- 但**单篇公开文章**通常可以用文章链接直接读取正文。应用新增“粘贴公众号文章链接”模式，只读取用户主动粘贴的公开文章，不登录、不使用 Cookie、不抓取账号历史。
- 遇到“环境异常/访问过于频繁/需要验证”时，应用明确提示改用复制全文粘贴。

### Wechat-spider 仓库

已检查 `nianpingy-cpu/Wechat-spider`：它通过登录公众号后台后的 Cookie、token、`searchbiz`/`appmsg`/`getappmsgext` 等内部接口批量获取文章和阅读量，需要 F12 抓包、手工填配置，存在账号风控和凭据泄露风险，不适合普通用户，也没有并入本应用。

> **安全提醒**：该仓库的 `get_urls_api.py` 中包含硬编码的 Cookie/token 字符串。应尽快在微信公众平台退出/重置相关会话，清理仓库中的凭据和 Git 历史，不要继续复用。

## 新交互

### 市场情报 → 添加情报

新增桌面端按钮“添加情报”，提供两个粘贴入口；需要登录时另有独立的“登录窗口采集（实验）”。

1. **公众号文章链接**：粘贴 1–10 篇 `https://mp.weixin.qq.com/s...` 公开文章链接，自动读取标题、作者、发布时间和正文；也支持上传包含公众号链接的 .txt/.csv 列表（如其他工具导出的 CSV）。
2. **抖音 / 小红书文案**：选择平台，粘贴分享文案、正文或链接；保存为待核实情报，自动提取第一个链接作为原文链接。

两个入口都明确显示：不需要登录平台账号，不需要 AppID/AppSecret，不读取密码或 Cookie。

### 登录窗口采集（实验）

需要登录的页面可在“添加情报”中打开独立平台窗口，手动登录后采集当前页。安全边界、支持范围和限制见[平台登录窗口与当前页采集验收](QA-v0.6.2-platform-login.md)。

### 企业技术接入

- 设置中的“来源连接（可选）”重命名为“企业技术接入”，默认折叠 AppID/AppSecret 表单，并明确“普通用户不用填”。
- 官方平台卡片保留官方登录/控制台入口和说明，但不再作为普通用户的主流程。
- 高级采集仍保留 RSS/Atom、公开网页订阅，适合有固定来源的企业。

## 后端

- `collect.start` 新增：
  - `kind: 'wechat-article'`：校验只接受 `https://mp.weixin.qq.com/s...`，使用公开网络请求读取，不携带 Cookie。
  - `kind: 'paste'`：保存用户粘贴内容，支持抖音/小红书/微信公众号/其他来源，保留用户粘贴的链接，不访问平台。
- 新增 `parseWechatArticle`：提取 `#activity-name`、`#js_name`、`#js_content`、`var ct` 时间，清洗脚本/样式，正文段落保留分隔。
- 公众号批量任务最多10篇；部分文章失败时保留成功结果并报告失败原因；全部失败则不写入。
- 粘贴内容按正文哈希去重，关联复盘待办仅在新增有效情报后完成。
- 手动链接只接受无凭据的 HTTP/HTTPS 地址，不抓取抖音/小红书分享页。

## 验证

- `npm run lint`：通过。
- `npm run typecheck`、`npm run typecheck:desktop`：通过。
- `npm test`：14 个测试文件、120 项测试通过；新增公众号链接校验、正文解析、粘贴保存/去重、非文章链接失败、快捷添加和登录窗口界面测试。
- `npm run desktop:build`：通过。
- `npm run desktop:test`：桌面持久化、导入导出、IPC 白名单与重启恢复通过。
- `node scripts/desktop-visual.mjs`：96 个桌面布局状态，0 失败。
- 未用真实公众号文章、真实抖音/小红书账号做联网验收；公开文章读取受微信风控影响，验证以解析器、失败提示和手工粘贴兜底为主。

## 仍未完成

- 官方平台 OAuth 登录、关键词搜索、账号历史文章批量抓取仍未实现。
- 抖音/小红书没有自动抓取，只能粘贴文案/链接；这比依赖 Cookie 的灰色爬虫更稳定、更适合企业用户。
- 公众号公开文章读取可能被微信要求验证；此时必须人工复制全文，不应绕过。
- 微信公众平台 Cookie/token 方案不并入产品。
