# v0.6.1 字体与排版验收

依据用户提供的浅色零售界面参考，采用偏黑、紧凑的粗标题，配合常规正文、浅灰辅助文字和清楚的数字层级。保留观策AI四页结构、海军蓝操作色和业务流程。

## 实现

- 自托管 Noto Sans SC Variable 5.3.1，中英文、表单与图表统一；字重100–900，禁止浏览器合成粗体。
- 页面标题760、分区标题680、正文400；标题字距收紧，大数字使用等宽数字特性。
- 字体文件随应用离线打包，不访问在线字体服务。SIL OFL 1.1完整许可随安装包分发，来源为Fontsource与Noto CJK。
- 图片仅作字重、字距、层级参考，未识别或复制其商业字体及品牌资产。
- 修复手机390px在150%近似缩放时策略/复盘操作按钮组撑出页面的问题：允许按钮组收缩换行，取消body固定最小宽度。
