# v0.6.2 独立审查与修复

2026-10-29，Issue #19。独立审查在0.6.1中复现了保存/同步阻断问题，原试用推荐已撤回；旧全绿测试没有覆盖这些时序。此版本保留原功能与字体，修复下列问题。

| 问题 | 实现与回归 |
|---|---|
| 在途保存失败时丢掉更新的输入、跨项目错写 | 保存队列绑定项目及基线，失败草稿保留；冲突时最新草稿也持久化为可处理版本 |
| 两端分别解决冲突后静默分叉、重置回历史内容不传播 | 同步使用独立事件ID和精确父事件，内容摘要不再充当因果；同时复决保留新冲突 |
| 任务完成刷新、同项目刷新、延迟切换覆盖新输入 | 共用编辑/显示/选择代次守卫，丢弃过时响应；接入任务面板、轮询、重置、去重导入与同步刷新 |
| 企业预算小数元被取整 | 保留整数分的两位小数往返，覆盖5000.49元和0.01元 |
| 变更服务地址带走旧凭据 | 模型站点改变必须明确填写新密钥；WebDAV站点/账号改变须重新填密码，更换目录须明确输入同步口令 |
| 公开采集地址分类与连接不一致 | 校验所有解析结果，并将同一批地址固定用于实际连接；保留TLS域名/证书校验、取消及压缩前后限额；不跟随重定向 |
| JSON数组中的错误条目导致整文件失败 | 逐条校验，保留有效记录与各条失败原因 |
| Atom正文/标题、合法命名空间前缀、xml:base处理错误 | 区分text/html/xhtml，保留内联顺序与实体，按命名空间识别字段并正确解析链接 |
| XHTML前缀非正文内容被当作证据；零新增错误完成待办 | 按标签本地名清除非正文节点，报告重复/缺正文；没有新增有效情报则保留关联待办 |
| A4复盘表裁切右侧指标、策略打印交互选择器 | 打印表格适应纸宽，输入改为完整静态数值；模型/采集操作区不进入报告 |

## 升级同步

本机旧数据库先自动备份，再升级schema3；原业务、审批与旧变更日志保留。同步协议升级为2，旧远端不会自动改写。先导出业务备份，所有设备安装新版后，配置**同一个新的空WebDAV目录**，旧目录保留。固定发现子目录名称仍为`guance-v1`，由manifest版本区分协议；不要把目录名误认为仍可与旧版混用。

新版连接旧目录在上传前明确拒绝；原0.6.1连接新版目录亦拒绝且未上传操作记录，见`review-v0.6.2/sync-protocol-compat.json`。独立设备升级形成多个检查点时，无法确定顺序的版本会保留冲突，需用户核对。
