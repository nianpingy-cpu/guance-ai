# 桌面试用版完整测试方案

记录提交号、系统、版本、视口/缩放、数据、步骤、期望/实际、截图与PASS/FAIL/未实测。协议测试服务不能代替真实账户、外部WebDAV或平台授权。使用独立测试目录，先备份业务数据。

| 测试层 | 场景 | 门槛与证据 |
|---|---|---|
| 页面 | 4页、所有折叠区、长文本、空/错状态；企业/导入/任务/证据/审批/复盘窗口；4设置页 | 无遮挡重叠和页面横向溢出；ui-verify、visual-verify、desktop-visual与人工截图复核 |
| 尺寸 | 1440×900、1366×768、1280×800、1024×768；100/125/150%原生Electron缩放；Web补平板/手机 | 操作可见、文字可读；桌面96状态、Web72状态。OS DPI另测 |
| 图表 | 标题/副说明、数值/单位、行标签/边界、提示框 | 自动碰撞检测加逐图人工复核，截图可追溯 |
| 预算审批 | 跨页预算、零/边界、超限、A/B编辑、理由、引用、不可变快照、依据变化复审 | 数据库事务重验，失败不写部分状态；单元/数据库/浏览器操作 |
| 复盘 | 教程输入、空值与0、负数、零分母、历史审批、建议去重/任务完成重开 | 指标按输入重算，不编造ROAS或因果；单元与Web交互 |
| 本地数据 | 多项目、关闭重开、直接退出、旧JSON迁移、重复/损坏导入、模式误改、创建回滚、升级备份 | 不静默覆盖或丢失，备份可读；database与desktop-verify |
| 模型 | 三协议、列表/手填、无默认、401/403/429/5xx、超时、取消、无效格式/引用、超预算、生成期间变更 | 不泄密、不静默重试、不覆盖已有结果；models与原生协议测试，真实模型另验 |
| 采集 | 网页/RSS/Atom、日期缺失、重复、DTD/私有网/平台限制、取消恢复、限流、文件逐行预览 | 有原文/时间/任务号；权限不足不可启动；collection/import及真实来源另验 |
| 同步 | 两端首次/重复、乱序、离线重连、并发冲突、选择版本、错账号/口令、篡改密文、凭据排除、分钟周期 | 幂等、不自动覆盖冲突、处理后收敛；sync与双原生进程，外部服务另验 |
| 权限边界 | Node关闭、导航/窗口/权限拒绝、CSP、IPC白名单与上限、凭据脱敏 | 外部文本不能读文件/执行命令；desktop-verify与独立代码审查 |
| 安装升级 | Windows全新安装/运行/覆盖升级/卸载保留；macOS两CPU安装；系统加密、签名与公证 | 各系统独立记录；构建不是人工安装证明 |
| 性能 | 1万短文本情报、分页/筛选/批量导入；补长正文与任务并行；参考4核8GB SSD | 筛选参考500ms内；任务不阻塞界面。desktop-performance记录实际硬件，基准机器另测 |

顺序：lint→前后端类型检查→单元/集成→构建→Web操作/图表→桌面存储/同步/96状态→真实模型和外部WebDAV→已启用官方平台逐个验证→两系统安装升级→独立审查和CI。

数据丢失、错误审批、密钥泄露、冲突覆盖、平台伪成功为阻断；主要操作不可用/关键文字遮挡为高优先级。缺陷修复保留RED/GREEN或前后截图并回归。已执行与未实测项目集中在RELEASE-v0.6.md；本方案的用例清单不构成已通过证明。
