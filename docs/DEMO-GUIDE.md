# 完整业务流程演示指南

建议演示环境：Chrome，1440×900 或 1440×1000，缩放 100%。  
开始前点击侧栏“恢复演示数据”，确保所有展示从同一个初始案例开始。

## 场景

- 企业：齐鲁茶研（虚构演示企业）
- 产品：250g 茶叶礼盒「齐鲁茶礼」
- 目标：一周内获取有效消费者咨询
- 预算上限：5,000 元
- 周期：2026-10-26 — 2026-11-01
- 初始状态：方案 A 已确认，已录入一轮模拟复盘数据；方案 B 为候选方案

## 演示步骤（约 5–7 分钟）

### 1. 工作台：快速判断本周任务

1. 打开 `/dashboard`。
2. 指出四张 KPI 卡：预算、情报量、重点信号、待确认建议。
3. 指出“近期市场信号变化”：每天一条竖线，红色外环表示当日含高优先级信号。
4. 指出“本周最值得关注”的三条信号及其来源、时间和原因。
5. 指出“当前营销任务”的阶段进度与下一项操作。

预期：用户能在 10–20 秒内回答“本轮在做什么、发生了什么、下一步做什么”。

### 2. 企业档案：编辑并保存

1. 点击顶部企业卡片或“编辑企业”按钮。
2. 修改“营销目标”或“规格 / 说明”。
3. 点击“保存资料”。

预期：抽屉关闭；刷新后修改仍在。  
可选高级演示：把预算改为 4,200 元，观察方案 A/B 超出上限、审批变为“需要重新确认”；在策略页点击“按比例调整至上限”后再确认。

### 3. 市场情报：筛选、核实与备注

1. 点击侧栏“市场情报”。
2. 在搜索框输入“担心”，列表立即缩小；再切换“待核实”状态。
3. 点击“担心‘包装好看但茶叶一般’”打开详情抽屉。
4. 展示：原始引用、模拟来源说明、观测事实、分析判断、待核实信息。
5. 修改底部“人工备注”，点击“保存备注”。
6. 点击“已核实”。

预期：工作台“重点市场信号/待核实记录”同步变化；若该记录属于当前方案证据，方案审批状态变为“需要重新确认”。  
提示观众：颜色不是唯一信号，优先级、状态和数字都同时显示。

### 4. 洞察与策略：从主题到证据

1. 点击“洞察与策略”。
2. 点击“礼盒体面感”“价格带与试错门槛”等主题，右侧证据清单随之切换。
3. 点击任一证据，跳回情报详情抽屉。
4. 指出“观测事实 / 营销机会推断 / 需要进一步核实”的区分。
5. 查看 A/B 两套方案：目标人群、平台、内容形式、核心信息、约束与不确定性。

预期：观众理解每一条洞察都能回到具体信号，而不是一段无法追溯的“AI 文案”。

### 5. 预算编辑与人工确认

1. 在“方案 A 渠道预算”中修改小红书预算（例如 2,000 → 2,200，抖音需相应下调）。
2. 观察预算合计、剩余额度与 A/B 预算图同步更新。
3. 若提示超出上限，点击“按比例调整至上限”。
4. 在“确认理由”中填写判断依据。
5. 点击“确认方案 A”。
6. 在确认弹窗中检查方案、预算、证据数量，点击“确认并保存快照”。
7. 在成功弹窗中点击“进入效果复盘”。

预期：生成新的审批快照；之后任何企业预算、方案内容或关键证据变化都会使状态回到“需要重新确认”。

### 6. 效果复盘：录入实际数据

1. 在“实际数据录入”表中修改任一渠道的花费、曝光、点击或咨询。
2. 观察顶部 KPI、CTR/CPC/咨询成本、计划与实际图、渠道效率图同步更新。
3. 把某个字段清空，观察聚合指标显示“暂无数据”，而不是 0。
4. 点击“编辑复盘备注”，填写观察、可能原因、无法确认的判断。
5. 在“需要补充的信息”中点击“加入下一轮情报任务”。

预期：观察、推测、待确认信息分开呈现；不计算 ROAS，不把渠道差异写成因果。

### 7. 闭环回情报页

1. 点击“前往情报页查看待办”或侧栏“市场情报”。
2. 顶部“下一轮待补情报”出现刚创建的任务。
3. 点击任务可定位关联情报；可标记完成或重新打开。

预期：复盘结论变成下一轮信息任务，形成“信息 → 洞察 → 决策 → 复盘 → 新信息”的闭环。

### 8. 持久化、导出与重置

1. 刷新浏览器，确认修改仍在。
2. 点击侧栏“导出当前任务 JSON”，展示导出文件。
3. 点击“恢复演示数据” → “确认恢复”，回到初始案例，方便重复演示。
4. 在策略页或复盘页点击“打印 / PDF”，可输出当前页面。

## 演示注意事项

- 全站顶部和页面内均标注“演示数据”，不要把它描述为真实企业案例或真实广告报表。
- “已收集 25 条情报”“10 个来源”等均为本地模拟数据。
- 方案中的“推荐”是人工预设分析与编辑结果，不是大模型实时生成；页面已明确说明。
- 没有真实平台采集、真实 API、真实成交/退款数据，因此不展示 ROAS 或因果结论。
