# 平台登录窗口与当前页采集验收（0.6.2）

2026-10-30，根据“给用户提供登录窗口，让他自己登录后采集”的要求，新增 Electron 独立登录窗口和“采集当前页面”能力。该能力是实验功能，不等同官方 OAuth，也不等于批量历史文章/关键词搜索。

## 用户流程

1. 市场情报 →“添加情报”→“登录窗口采集（实验）”。
2. 选择抖音、小红书或公众号文章页。
3. 点“打开登录窗口”，在独立窗口扫码/登录，并打开一篇视频、笔记或公众号文章。
4. 回到“添加情报”，点“采集当前页面”。
5. 结果进入市场情报，标记为待核实，保留标题、原文链接和正文。

登录窗口可以粘贴一个链接后直接打开；不填则打开平台首页。公众号文章链接可直接打开，公开文章一般无需登录。

## 支持范围

- **微信公众号**：读取公开文章页 `#js_content` 的标题和正文。已用真实公开文章验证。
- **小红书**：详情页读取标题、正文；搜索页读取当前可见的 `/explore/` 或 `/discovery/item/` 链接（标题级）。
- **抖音**：详情页读取视频描述；搜索页读取当前可见的 `/video/` 链接（标题级）。
- 最多一次保存 20 条；搜索页只保存链接和标题，正文需打开详情页再采集。
- 不抓取账号历史、不做关键词自动翻页、不导出评论/阅读量。

## 安全边界

- 独立 `BrowserWindow`，`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`。
- 只允许 HTTPS 导航；外部弹窗使用同一隔离分区。
- 不注入 remote 页面的 preload，不读取密码字段，不导出 Cookie。
- 登录状态保存在 `persist:guance-<platform>` 本机分区，可在界面点“清除登录状态”清除。
- 页面读取只在用户点击“采集当前页面”时执行，并在 Electron isolated world 中运行，避免页面脚本篡改采集逻辑。
- 平台改版、登录验证、风控或账号异常可能导致采集失败；风险由使用者自行承担。

## 验证

- 打开抖音登录窗口：成功创建第二个窗口并加载 `https://www.douyin.com/...`。
- 公众号公开文章：在登录窗口打开真实文章并采集，返回标题、链接和正文。
- `npm run lint`、`npm run typecheck`、`npm run typecheck:desktop`：通过。
- `npm test`：14 个测试文件、120 项测试通过（新增登录窗口 UI 测试）。
- `npm run build`、`npm run desktop:build`：通过。
- `node scripts/desktop-visual.mjs`：96 个桌面布局状态，0 失败。
- 抖音/小红书详情页和搜索页未用真实登录账号逐一验收；页面结构变化可能导致选择器失效。

## 仍未完成

- 官方 OAuth 登录、关键词搜索、账号历史文章批量抓取仍未实现。
- 没有集成 MediaCrawler/wechatDownload 等外部项目；它们仍可作为技术同事的外部工具，但许可证、依赖和平台条款需自行评估。
- 登录窗口是“手动登录 + 当前页读取”，不能承诺长期稳定；应作为实验功能，正式商用前需单独安全、合规和平台授权评估。
