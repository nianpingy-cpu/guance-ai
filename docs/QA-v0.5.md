## 测试先行证据

原有 20 项测试通过。新增四项回归测试，首次执行：21 PASS、3 FAIL：

1. 零花费、正点击/咨询分母应返回 0 成本，原实现返回 null。
2. 同一毫秒确认两次的审批 ID 应唯一，原 Date.now ID 冲突。
3. 不存在的复盘渠道应拒绝，原实现返回成功但不保存。

修复：保留分母检查、去掉对零花费的错误排除；新增记录采用 randomUUID；校验渠道属于审批方案。第四项确认预算变更触发复审、超预算拒绝且旧快照保持不变。

浏览器验收另证明“恢复演示数据”没有按原提示返回工作台：waitForURL 超时；补上路由跳转后重新验收。

## 全页面 UI 监控与验收

脚本：`npm run ui:verify`。使用实际 Chrome、1440×1000 / 768×1024 / 390×844，逐一导航四页，保存全页截图、检查标题与 document 横向溢出。没有用静态页面截图代替浏览器运行。

典型操作：手机导航与企业/证据抽屉，A/B 切换及人工编辑，预算修改→跨页持久化→复审，超预算拒绝→调整→确认快照，筛选与空状态，证据重要性与备注，主题回到来源，逐渠道输入与 CTR 重算，任务回流，JSON 导出与重置。

本机 22 项浏览器检查全部通过，控制台/pageerror 为 0；24 项单元测试、lint、typecheck、生产 build 全通过。机器记录见 [ui-verification.json](ui-verification.json)。图表、抽屉与全页截图见 [screenshots/](screenshots/)。

## 发现与修复

| 问题 | 修复 | 验证 |
|---|---|---|
| 工作台多层卡片与重复数据 | 单一指标带、一个趋势图、重点记录与进展 | 实际浏览桌面/手机截图 |
| 情报清单被 KPI/图表/待办挤到下方 | 统计简化，分布图折叠，任务摘要一行 | 筛选、证据、任务仍可操作 |
| 策略比较位于长篇分析下方 | A/B 与预算优先，主题/证据分析按需展开 | 人工编辑及来源跳转 |
| 复盘图表和快照反复呈现预算 | 四项指标、输入优先，比较图按需展开 | 真实输入重算与持久化 |
| 手机 SVG 标签缩小难读 | 增大标签并在图内横向滚动 | 三视口截图与交互 |
| 放大图表后策略页宽度 688px 溢出 | grid 子项 min-width:0 | 390px document 宽度通过 |
| 关闭手机导航仍有阴影且元素留在 DOM | 关闭时卸载 | 手机截图及导航操作 |
| 减少动画时截图提前出现空图 | reduced-motion 同时清零 animation-delay | 全页截图数据点可见 |
| 原恢复操作提示与路由行为不一致 | 恢复后返回工作台 | 浏览器断言 |

## 结果与限制

本轮是有限次数实际验收，不是后台持续监控，也不宣称所有浏览器都验证过。Windows Chrome 实操；Linux Chromium 由远端 CI 执行。lint、typecheck、单元测试、build、UI 脚本的最终结果以提交与 CI 为准。

保持纯前端；数据与预设分析是模拟，不代表真实营销成效。localStorage 不是可信审计存储。长列表和移动端横向表格/图表仍需滚动查看。
