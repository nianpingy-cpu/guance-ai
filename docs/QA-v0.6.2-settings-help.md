# 设置填写说明修复与验收（0.6.2）

2026-10-29，根据试用反馈修复“官方平台应用ID/密钥不知道怎么填、WebDAV 不会配置”的问题。Issue #21，分支 `feat/21-settings-help`。

## 用户问题

1. 设置里的抖音、微信公众号、小红书“应用ID / 应用密钥”只有字段名，没有说明是什么、去哪里找。
2. 用户希望有登录跳转或直接登录，但不清楚本版是否支持官方登录。
3. WebDAV 地址、用户名、密码、同步口令的含义混在一起，不知道如何开始。

## 界面修改

### 设置 → 企业技术接入

- 首屏明确：应用ID/密钥不是账号密码，不要填公众号密码、抖音号密码、小红书密码或验证码。
- 明确：本版没有接入官方登录和数据适配器，填了凭据也不会启用平台采集。
- 微信公众号、小红书、抖音分别提供：
  - 官方登录/控制台 HTTPS 入口，点击用系统浏览器打开；
  - AppID 与 AppSecret 所在菜单；
  - 平台资质、权限和关键词搜索限制；
  - 常见错误与密钥泄露后的处理。
- 显示每个平台已保存的 AppID 与是否已保存密钥；首次保存要求同时填写 AppID 和密钥。
- 增加“为什么没有一键登录/直接登录”的说明：官方 OAuth 需要审核通过的应用、登记回调地址、授权流程和数据适配器，目前均未完成，因此不放会失败的假按钮。
- 从情报页/策略页打开设置时，直接定位到对应设置标签。

### 设置 → 跨设备同步（WebDAV）

- 首屏解释 WebDAV 是可选“网络文件夹”，不配置也能正常使用。
- 提供“三步完成”说明，明确不用手动建文件夹。
- 增加坚果云一键填入地址；列出坚果云、Nextcloud、群晖的地址、用户名和密码来源。
- 增加“生成”按钮：生成本地 20 位分组同步口令，并尝试复制到剪贴板。
- 将“保存配置”和“测试并初始化目录”合并为“保存并测试连接”；成功测试会清除旧错误提示。
- 明确区分 WebDAV 密码（网盘登录/应用密码）与独立同步口令（加密远端文件）。
- 保留冲突处理、停用同步、自动同步和凭据不外传等原有行为。
